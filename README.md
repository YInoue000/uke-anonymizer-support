# UKE匿名化専用 — 公開案内

アプリの使い方・プライバシーポリシー・サポートを掲載する静的サイトです。
このリポジトリには、アプリ本体・ソースコード・入力UKE・仮名化結果・鍵・プロファイル・DBを置きません。

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root)

- `index.html`: アプリ紹介・使い方
- `privacy.html`: プライバシーポリシー
- `support.html`: サポート・FAQ
- `.github/ISSUE_TEMPLATE/`: 実データを含めない問い合わせ用フォーム

サポートの投稿は公開されます。患者情報・施設名・UKE・鍵・プロファイルは投稿しないでください。
